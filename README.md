# AI Resume Analyzer

AI-powered Resume, Job Match and Career Skill Analyzer.

## 🚀 Features

- 🎯 Resume and Job Description Matching
- 📊 Semantic Similarity Analysis
- 🧠 Skill Detection from Resume
- 🚀 Career Skill Analysis
- 🏛️ Government Exam Guide
- 📚 Exam Information Pages
- 🔗 Official Government Information Links

## 🛠️ Technologies Used

- Python
- Flask
- Sentence Transformers
- Scikit-learn
- PyPDF
- HTML
- CSS
